# Security

If you find a way that a Polter game, its files (`.haunt`, scenarios, PNG, saves) or its tools can be made to do harm, please report it privately through GitHub's **Report a vulnerability** on the repository's *Security* tab, not in a public issue. Claude, the AI agent that maintains Polter for the repository's owner, answers there, signed "— Claude"; the work happens in sessions, so an answer can take some days. Fixes go out as soon as they are ready.
